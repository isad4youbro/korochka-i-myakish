# Корочка и Мякиш — сайт кофейни

Готовый сайт для кофейни-пекарни «Корочка и Мякиш» в Шушарах. Чистый HTML/CSS/JS,
без сборки и зависимостей — можно открыть прямо в браузере или выложить на
GitHub Pages за 5 минут.

```
korochka-i-myakish/
├── index.html              ← вся разметка страницы
├── css/style.css            ← все стили
├── js/data.js                ← ТУТ меню, цены, отзывы, телефон, адрес — правите вы
├── js/main.js                 ← логика (обычно трогать не нужно)
└── assets/img/
    ├── logo.png                ← ваш логотип (уже вставлен, взят с ваших скриншотов)
    ├── hero-storefront.jpg      ← фото вывески на главном экране (тоже уже вставлено)
    ├── favicon-*.png             ← иконка вкладки браузера
    └── products/                  ← СЮДА кладёте фото напитков (пока пусто)
```

## 1. Посмотреть сайт прямо сейчас

Проще всего — открыть `index.html` двойным щелчком в браузере. Почти всё будет
работать. Но лучше запустить локальный сервер (тогда точно всё будет как надо,
включая шрифты и карту):

**Если есть Python:**
```bash
cd korochka-i-myakish
python3 -m http.server 8000
```
Затем откройте в браузере `http://localhost:8000`.

**Если есть VS Code** — поставьте расширение «Live Server» и нажмите
«Go Live» внизу окна.

---

## 2. Выложить на GitHub Pages (бесплатный хостинг)

1. Создайте новый репозиторий на GitHub (например, `korochka-i-myakish`).
   Публичный или приватный — для GitHub Pages подходит и то, и другое
   (на бесплатном тарифе Pages работают с публичных репозиториев).
2. Загрузите в него содержимое папки `korochka-i-myakish` **целиком**,
   так, чтобы `index.html` лежал в корне репозитория (не во вложенной папке).
   Через веб-интерфейс GitHub: кнопка **Add file → Upload files** — перетащите
   всё содержимое папки. Либо через git:
   ```bash
   cd korochka-i-myakish
   git init
   git add .
   git commit -m "Первая версия сайта"
   git branch -M main
   git remote add origin https://github.com/ВАШ_ЛОГИН/korochka-i-myakish.git
   git push -u origin main
   ```
3. В репозитории откройте **Settings → Pages**.
4. В разделе **Build and deployment** выберите **Source: Deploy from a branch**,
   ветку **main** и папку **/ (root)**. Нажмите **Save**.
5. Подождите 1–2 минуты и обновите страницу — вверху появится ссылка вида:
   ```
   https://ВАШ_ЛОГИН.github.io/korochka-i-myakish/
   ```
   Это и есть готовый адрес сайта. Можно вести на него людей, вставлять в
   Яндекс.Бизнес как «сайт компании» и т. д.

После этого при каждом изменении файлов в репозитории (например, вы добавили
новое фото) сайт сам обновится за минуту-две — ничего дополнительно нажимать
не нужно.

## 3. Добавить свои фотографии

Пока фото нет — вместо него аккуратно показывается фирменная плашка с иконкой
чашки, сайт не ломается. Как только вы положите файл с правильным именем в
`assets/img/products/`, фото подхватится само, ничего в коде менять не нужно.

**Нужны файлы ровно с такими именами** (регистр важен, формат `.jpg` или
поменяйте расширение в `js/data.js`, если у вас `.png`):

| Файл в `assets/img/products/` | Напиток |
|---|---|
| `espresso.jpg` | Эспрессо |
| `americano.jpg` | Американо |
| `cappuccino.jpg` | Капучино |
| `latte.jpg` | Латте |
| `flat-white.jpg` | Флэт Уайт |
| `glace.jpg` | Гляссе |
| `tea-black.jpg` | Чай чёрный |
| `tea-craft.jpg` | Чай крафтовый |
| `cocoa.jpg` | Какао |
| `milkshake.jpg` | Молочный коктейль |

Советы по самим фото:
- Квадратные или почти квадратные кадры (соотношение примерно 4:3) — карточки
  сами подрежут под нужную форму, но лучше, чтобы напиток был по центру.
  Разрешение — от 800×800 px, больше тоже подойдёт без проблем.
- Старайтесь снимать в одном стиле/фоне/освещении — так каталог будет выглядеть
  цельным, а не как случайный набор фото из интернета.
- Файлы можно сжать перед загрузкой (например, на squoosh.app), чтобы сайт
  быстрее грузился — 150–400 КБ на фото обычно достаточно.

**Хотите поменять фото на главном экране или логотип** — просто замените
файлы `assets/img/hero-storefront.jpg` и `assets/img/logo.png` на свои,
сохранив те же имена.

## 4. Поменять меню, цены, состав

Всё меню — в файле `js/data.js`, в массиве `PRODUCTS`. Каждый напиток выглядит так:

```js
{
  id: "cappuccino",              // используется для имени файла фото — не трогайте
  category: "coffee",             // coffee / tea / cocoa / milkshake
  name: "Капучино",
  tagline: "Короткое описание под названием",
  composition: "Состав напитка",
  image: "assets/img/products/cappuccino.jpg",
  sizes: [
    { label: "S", volume: "250 мл", price: 190 },
    { label: "M", volume: "350 мл", price: 210 },
    { label: "L", volume: "450 мл", price: 230 },
  ],
},
```

Чтобы **добавить новый напиток** — скопируйте один из блоков `{ ... }` целиком,
вставьте перед закрывающей `];` массива и поправьте значения. Чтобы **убрать
напиток** — удалите его блок целиком. Составы указаны обобщённо (по классическим
рецептам) — поправьте под свою рецептуру, если она отличается.

## 5. Отзывы

### Как есть сейчас
На сайте показаны 4 реальных отзыва с вашей карточки на Яндекс Картах — они
лежат в `js/data.js`, в массиве `REVIEWS`. Формат такой же простой, как у
меню — можно скопировать блок и вписать новый отзыв вручную, если захотите
обновить подборку.

Рейтинг и счётчики (`rating`, `ratingsCount`, `reviewsCount` в объекте
`CONFIG` в начале `js/data.js`) на момент сборки сайта были **4.8 · 83 оценки ·
58 отзывов** (актуальнее, чем на вашем старом сайте, где отображалось 25) —
их стоит периодически обновлять руками по факту.

### Отзывы: подключаем официальный виджет Яндекса
Живая автоматическая подгрузка отзывов technически возможна только через
официальный виджет Яндекса (у Яндекса нет открытого бесплатного API для
чужих сайтов) — зато подключается он в 2 минуты:

1. Откройте карточку организации на Яндекс Картах → **Поделиться** →
   вкладка **«Виджет с отзывами»**.
2. Настройте внешний вид (тема оформления, размер) и нажмите **«Скопировать код»**.
3. В файле `index.html` найдите комментарий
   `Отзывы: подключаем официальный виджет Яндекса` (секция `id="reviews"`)
   и вставьте полученный `<iframe ...>` вместо блока с `.reviews-summary`
   и `.review-grid` (или рядом с ним).

Так отзывы будут обновляться сами, без вашего участия.

## 6. Карта и контакты

Карта на сайте — это официальная встраиваемая карта Яндекса по ID вашей
организации (`170474682334`), без ключей API, ничего дополнительно
настраивать не нужно.

**Важно проверить:** на момент сборки сайта карточка организации на Яндекс
Картах показывала статус **«закрыто / не работает»**. Возможно, это просто
не обновлено в вашем личном кабинете Яндекс.Бизнеса — стоит зайти и
проверить статус и часы работы, чтобы кнопка «Проложить маршрут» не пугала
людей пометкой о закрытии.

Часы работы на сайте сейчас — заглушка («Уточняйте по телефону»), потому что
на карточке Яндекса они не были указаны. Впишите реальные часы в
`js/data.js` → `CONFIG.hours`, например:
```js
hours: "Пн–Вс: 8:00–21:00",
```

Телефон, адрес и остальные данные — там же, в объекте `CONFIG` в начале файла.

## 7. SEO и превью для соцсетей

В `index.html` есть блок `<script type="application/ld+json">` со
структурированными данными (название, адрес, телефон, рейтинг) — это
помогает Google и Яндексу показывать сайт богаче в поиске. Если меняете
адрес/телефон/название в `js/data.js` — поправьте те же значения и в этом
блоке (он в `<head>`, ищите по комментарию «Структурированные данные»).

После публикации на GitHub Pages поправьте в `<head>` ссылки
`og:image` и добавьте `og:url` на реальные адреса вида
`https://ВАШ_ЛОГИН.github.io/korochka-i-myakish/...` — тогда превью
ссылки в мессенджерах и соцсетях будет с корректной картинкой.

**Важно:** адрес, телефон и часы работы продублированы прямо в HTML
(в шапке, в блоке контактов и в подвале) — это сделано специально, чтобы
эта важная информация была видна поисковикам и людям, даже если
JavaScript почему-то не загрузится. Значит, если вы меняете телефон или
адрес, их нужно поправить в **двух местах**: в `js/data.js` (для сайта
с работающим JS) и в самом `index.html` (эти же строки, для надёжности) —
проще всего искать по старому значению через «Найти и заменить» в
редакторе кода.

## 8. Частые вопросы

**Можно ли открыть сайт без интернета?** Почти всё — да, кроме шрифтов
(Google Fonts) и карты (Яндекс) — для них нужен интернет, как и на любом
обычном сайте.

**Ничего не отображается / пустая страница** — откройте сайт через локальный
сервер (см. пункт 1), а не через `file://`, и проверьте консоль браузера
(F12 → Console) на ошибки.

**Как поменять цвета/шрифты** — все цвета собраны в самом начале файла
`css/style.css`, в блоке `:root { ... }` — там подписано, за что отвечает
каждая переменная.
