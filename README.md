# Корочка и Мякиш — сайт кофейни

```
korochka-i-myakish/
├── index.html              ← вся разметка страницы
├── css/style.css            ← все стили
├── js/data.js                ← ТУТ меню, цены, отзывы, телефон, адрес
├── js/main.js                 ← логика
└── assets/img/
    ├── logo.png                ← ваш логотип 
    ├── hero-storefront.jpg      ← фото вывески на главном экране 
    ├── favicon-*.png             ← иконка вкладки браузера
    └── products/                  ← фото напитков
```

## 1. Поменять меню, цены, состав

Всё меню — в файле `js/data.js`, в массиве `PRODUCTS`. Каждый напиток выглядит так:

```js
{
  id: "cappuccino",              // используется для имени файла фото — не трогайте
  category: "coffee",             // coffee / tea / cocoa / milkshake
  name: "Капучино",
  tagline: "Короткое описание под названием",
  composition: "Состав напитка",
  image: "assets/img/products/cappuccino.jpg",
  sizes: [
    { label: "S", volume: "250 мл", price: 190 },
    { label: "M", volume: "350 мл", price: 210 },
    { label: "L", volume: "450 мл", price: 230 },
  ],
},
```

Чтобы **добавить новый напиток** — скопируйте один из блоков `{ ... }` целиком,
вставьте перед закрывающей `];` массива и поправьте значения. Чтобы **убрать
напиток** — удалите его блок целиком. Составы указаны обобщённо (по классическим
рецептам) — поправьте под свою рецептуру, если она отличается.

## 2. Отзывы

### Как есть сейчас
На сайте показаны 4 реальных отзыва с карточки на Яндекс Картах — они
лежат в `js/data.js`, в массиве `REVIEWS`. Формат такой же простой, как у
меню — можно скопировать блок и вписать новый отзыв вручную, если захотите
обновить подборку.

Рейтинг и счётчики (`rating`, `ratingsCount`, `reviewsCount` в объекте
`CONFIG` в начале `js/data.js`) на момент сборки сайта были **4.8 · 83 оценки ·
58 отзывов** — их стоит периодически обновлять руками по факту.

### Отзывы: подключаем официальный виджет Яндекса
Живая автоматическая подгрузка отзывов технически возможна только через
официальный виджет Яндекса (у Яндекса нет открытого бесплатного API для
чужих сайтов) — зато подключается он в 2 минуты:

1. Откройте карточку организации на Яндекс Картах → **Поделиться** →
   вкладка **«Виджет с отзывами»**.
2. Настройте внешний вид (тема оформления, размер) и нажмите **«Скопировать код»**.
3. В файле `index.html` найдите комментарий
   `Отзывы: подключаем официальный виджет Яндекса` (секция `id="reviews"`)
   и вставьте полученный `<iframe ...>` вместо блока с `.reviews-summary`
   и `.review-grid` (или рядом с ним).

Так отзывы будут обновляться сами, без вашего участия.

## 3. Карта и контакты

Карта на сайте — это официальная встраиваемая карта Яндекса по ID вашей
организации (`170474682334`), без ключей API, ничего дополнительно
настраивать не нужно.

Часы работы на сайте сейчас — заглушка («Уточняйте по телефону»), потому что
на карточке Яндекса они не были указаны. Впишите реальные часы в
`js/data.js` → `CONFIG.hours`, например:
```js
hours: "Пн–Вс: 8:00–21:00",
```

Телефон, адрес и остальные данные — там же, в объекте `CONFIG` в начале файла.

## 4. SEO и превью для соцсетей

В `index.html` есть блок `<script type="application/ld+json">` со
структурированными данными (название, адрес, телефон, рейтинг) — это
помогает Google и Яндексу показывать сайт богаче в поиске. Если меняете
адрес/телефон/название в `js/data.js` — поправьте те же значения и в этом
блоке (он в `<head>`, ищите по комментарию «Структурированные данные»).

**Важно:** адрес, телефон и часы работы продублированы прямо в HTML
(в шапке, в блоке контактов и в подвале) — это сделано специально, чтобы
эта важная информация была видна поисковикам и людям, даже если
JavaScript почему-то не загрузится. Значит, если вы меняете телефон или
адрес, их нужно поправить в **двух местах**: в `js/data.js` (для сайта
с работающим JS) и в самом `index.html` (эти же строки, для надёжности) —
проще всего искать по старому значению через «Найти и заменить» в
редакторе кода.
